Plan API

Generates and serves TrainingPlans. The name is the C4 container name.

Generate a TrainingPlan

Generates a TrainingPlan for the authenticated User from a stated Goal. The plan is stored with status DRAFT. Refused when the User already has an unfinished plan (ADR-0002).

Authorizations:
bearerAuth
Request Body schema: application/json
required
goal
required
string (Goal)
Enum: "STRENGTH" "ENDURANCE" "WEIGHT_LOSS"

The training goal stated by the Athlete.

weeks
integer [ 1 .. 24 ]
Default: 8

Plan length in weeks.

Responses

Production

https://api.personal-trainer.dev/v1/plans

Log a completed Session

Logs a completed workout against the User's ACTIVE TrainingPlan and triggers recalculation of the remaining weeks (ADR-0001). Past weeks are never rewritten.

Authorizations:
bearerAuth
Request Body schema: application/json
required
planId
required
string <uuid>

The ACTIVE TrainingPlan this Session belongs to.

completedAt
required
string <date-time>
durationMinutes
required
integer [ 1 .. 600 ]
perceivedEffort
integer [ 1 .. 10 ]

Athlete rating used as the adaptation signal.

Responses

Production

https://api.personal-trainer.dev/v1/sessions

Read a TrainingPlan

Returns the TrainingPlan including its adapted remainder. The first successful read moves a DRAFT plan to ACTIVE (FR-2).

Authorizations:
bearerAuth
path Parameters

required
string <uuid>

TrainingPlan identifier.
